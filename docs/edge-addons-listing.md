### 详细描述（完整版，可直接复制）

```
Quick Copy Ext 是一个面向 Web 开发者和测试人员的浏览器扩展，旨在减少异常反馈时前后端的沟通成本。

主要功能：

• 自动捕获接口请求记录 — 监听当前页面的 XHR 请求，自动收集 URL、方法、状态码、请求/响应头、traceId、耗时等信息。
• 智能过滤与勾选 — 支持按接口前缀地址过滤请求列表，可单选或按住 Shift 连续多选异常接口。
• 一键复制标准化反馈 — 将勾选的接口信息、页面 URL、页面标题等整理为结构化文本，一键复制到剪贴板。
• 响应规则异常检测 — 支持自定义响应体判断规则（如 res.rtn !== 0），自动标记业务逻辑异常。
• Apifox 接口关联 — 支持对接本地 Apifox 导出服务，自动关联接口文档地址和接口名称。
• 自定义字段 — 支持添加自定义字段（如"反馈人-张三"），随反馈内容一并复制。
• 快速填入模板 — 支持预设常见反馈模板，快速选择填入备注。
• 配置导入/导出 — 监听规则、过滤规则等配置支持 JSON 导入导出，方便团队共享。

适用场景：

• 测试人员提交 Bug 时，快速提供完整的接口异常信息。
• 前后端联调时，快速整理接口调用记录供双方确认。
• 日常开发中，需要复制某组接口信息进行讨论和分析。
```

## 2. 隐私与权限

### 2.1 权限声明（Permissions）

> Edge 合作伙伴中心的权限声明需逐条填写用途。

| 权限 | 用途说明 |
|------|----------|
| **activeTab** | 获取当前活动标签页的 URL 和页面标题，用于在反馈内容中附带页面信息。仅在用户点击扩展图标时临时生效。 |
| **tabs** | 监听标签页 URL 变化（如 SPA 路由切换）以重新判断是否需要捕获请求；在标签页关闭时自动清理该标签页的请求记录缓存；初始化时遍历所有标签页建立监听范围。 |
| **webRequest** | 监听页面 XMLHttpRequest 的发起、完成和错误事件，自动捕获请求 URL、HTTP 方法、状态码、请求头（含 traceId）、响应耗时等调试信息。扩展仅读取请求头中的 traceId，不读取或修改请求体/响应体内容。 |
| **storage** | 使用 `storage.sync` 持久化用户配置（监听域名规则、接口前缀过滤、自定义字段等）；使用 `storage.session` 在会话期间缓存请求记录和 Apifox 接口数据。 |

### 2.2 主机权限（Host Permissions）说明

| 权限 | 用途说明 |
|------|----------|
| **<all_urls>** | 扩展需要在用户指定的域名上监听 XHR 请求以捕获调试信息。需要 <all_urls> 权限以支持用户在配置中添加任意监听域名。扩展仅在用户配置的监听域名范围内记录请求。默认监听范围仅为 localhost 和 127.0.0.1，用户可在设置中自行添加其他域名。 |

### 2.3 Content Script 说明

扩展在所有页面注入 content script，用于注入辅助脚本以捕获接口响应体数据。详见"数据收集说明"。

### 2.4 数据收集说明

请在 Edge Add-ons 的 "Data Usage" 部分填写：

```
数据收集与使用：

1. 扩展不会收集、上传或分享任何用户数据到远程服务器。
2. 所有数据（包括接口请求记录、URL、页面标题、响应体快照）仅在本地浏览器中处理，不会离开用户的设备。
3. 用户配置通过 chrome.storage.sync 保存，仅用于在已登录同一 Microsoft 账号的 Edge 浏览器之间同步配置。
4. 扩展不会读取或存储用户的浏览历史、书签、密码或其他个人信息。
5. 扩展仅在用户点击扩展图标打开弹出面板时，才会读取当前标签页的信息并展示捕获的请求记录。
6. 请求记录的响应体快照仅用于业务异常规则判断（如 res.rtn !== 0），快照大小经过裁剪（最多 20 个 key、嵌套 3 层、字符串截断至 300 字符），不会完整存储大型响应。
7. 扩展不会向任何第三方服务发送数据。
```

### 2.5 是否需要说明 Edge 特定 API

Edge 商店中不需要额外说明。扩展的 manifest 使用标准 MV3 API，与 Edge 完全兼容，无需特殊适配。

## 5. 验证信息

### 发布者验证

Edge Add-ons 需要 Microsoft 账号注册开发者。如有需要，可通过以下方式关联 GitHub 仓库进行验证：

- 开发者注册：https://partner.microsoft.com/
- 需要设置开发者资料（名称、邮箱等）

### 包上传

- 需要上传 ZIP 格式的扩展包
- ZIP 包必须包含 `manifest.json` 在根目录
- Manifest 版本：3

### 打包命令

```bash
# 构建 Edge 版本（与 Chrome 版本相同构建流程）
pnpm build:chrome

# 打包为 ZIP
cd dist_chrome && zip -r ../quick-copy-ext-v1.4.32-edge.zip . && cd ..
```

> **注意**：Edge Add-ons 目前支持加载 Chrome 兼容的扩展包。可以直接使用 Chrome 构建产物（`dist_chrome/`），无需额外适配。如果未来 Edge 有特殊要求，可调整 `manifest.json` 中的 `minimum_edge_version` 等字段。
