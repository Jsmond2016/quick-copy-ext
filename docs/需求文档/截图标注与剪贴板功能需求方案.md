# Quick Copy Ext 截图标注与剪贴板功能需求方案

> **更新时间**：2026-07-24；**使用模型**：GPT-5；**用户**：Jsmond2016

---

## 背景与目标

问题反馈除了接口、页面错误和录屏，还需要快速传递页面上可见的异常位置。用户在浏览器中切换到外部截图工具会打断排查流程，也容易遗漏标记信息。

本功能提供当前可视区域截图、裁剪和常见标注能力。用户从 Popup、页面右键菜单或快捷键进入截图，完成编辑后自动把最终 PNG 图片写入系统剪贴板，能够直接粘贴到缺陷平台、即时通信工具或文档中。

## 用户与使用场景

- 开发或测试发现页面布局、文案、交互状态异常，需要圈出具体位置并说明顺序。
- 用户刚完成录屏或接口采集，需要补一张静态证据图。
- 用户希望不打开 Popup，直接使用右键菜单或快捷键完成截图。

## 范围与优先级

### P0：首期必须交付

- 截取当前活动标签页的当前可视区域，原图格式为 PNG。
- 支持三个入口：Popup 的“截图并标注”按钮、页面空白处右键菜单“Quick Copy：截图并标注”、快捷键。
- 默认快捷键为 macOS `Option+1`，Windows/Linux `Ctrl+1`；用户可在浏览器扩展快捷键页修改。
- 截图后在当前页面上进入全屏编辑态，原页面作为暗化背景，不跳转新标签页。
- 支持裁剪框选、矩形框、箭头、自由画笔、数字标记、文本标记。
- 支持颜色、线宽、撤销、反撤销、清空全部编辑、删除选中标注、取消和完成。
- 点击“完成”后自动复制最终 PNG 到系统剪贴板，并显示成功或失败提示；成功后关闭编辑器。
- 最终 PNG 右下角添加低干扰水印：小尺寸 Quick Copy Ext 图标与文字，约 38% 透明度，不遮挡用户标注和主要内容。
- 不上传截图，不在扩展内保留图片历史；取消、完成或发生错误后释放内存中的截图数据。

### P1：首期稳定后评估

- 马赛克/模糊遮挡，解决手机号、姓名和业务数据脱敏需求。
- 椭圆框、直线、高亮半透明填充、放大镜等高级标注。
- 下载 PNG、复制失败后的重试与另存为备用入口。
- 与异常反馈记录关联，在复制文本中显示“截图已复制”的会话提示。

### 本期不包含

- 整页滚动截图、跨标签页拼接、浏览器窗口或桌面截图。
- 多张截图历史、云端存储、多人协作标注。
- 视频帧编辑、OCR、AI 自动识别异常。
- Firefox 截图实现。首期仅在 Chrome 构建启用，Firefox 构建隐藏入口。

## 入口与流程

### Popup

1. 用户在任意可截图的 HTTP(S) 页面打开 Popup，点击“截图并标注”。
2. Popup 关闭后，扩展立即截取当前可视区域并在原页面打开编辑器。
3. 用户完成裁剪和标注，点击“完成”。
4. 扩展自动写入剪贴板，页面提示“截图已复制，可直接粘贴”。

### 右键菜单

1. 用户在 HTTP(S) 页面空白处右键。
2. 选择“Quick Copy：截图并标注”。
3. 后续流程与 Popup 相同。

右键菜单不依赖当前页面是否已配置接口监听 Origin；截图是独立的本地工具能力。

### 快捷键

1. 用户在当前 Chrome 窗口按下 macOS `Option+1` 或 Windows/Linux `Ctrl+1`。
2. 扩展对当前活动标签页执行截图并打开编辑器。

快捷键仅在 Chrome 已聚焦时生效，不作为系统全局快捷键。若浏览器保留快捷键优先级导致默认键位未注册，扩展应在 Popup 中展示当前实际快捷键，并提示用户到 `chrome://extensions/shortcuts` 修改。`Ctrl+1` 可能与浏览器切换第一个标签页冲突，必须在目标 Chrome 版本上实测后决定是否保留默认值或改为 `Ctrl+Shift+1`。

## 编辑器交互规格

### 基础规则

- 编辑器覆盖当前页面视口；截图原图按比例完整展示，不拉伸变形。
- 初始状态为“框选”工具，默认裁剪选区为整张图；用户需要裁剪时可切换“裁剪”工具并拖拽选区边和角。
- 裁剪框以外区域使用半透明遮罩；标注允许超出裁剪框显示，但导出时只保留裁剪范围内内容。
- `Esc` 取消并关闭编辑器；`Enter` 等同“完成”。编辑器打开期间拦截页面鼠标、滚轮与快捷键，防止误操作业务页面。
- 视口尺寸变化、页面导航、标签页关闭或截图会话被新的截图请求替换时，当前编辑会话关闭并提示原因。

### 工具与参数

| 工具 | 行为 | 默认值 |
|:---|:---|:---|
| 裁剪 | 拖拽、调整选区，决定最终图片范围 | 全图 |
| 矩形框 | 拖拽绘制无填充矩形，适合框选异常元素 | 红色、2 px |
| 箭头 | 从起点拖至终点，箭头始终在终点 | 红色、2 px |
| 画笔 | 按住拖动自由绘制 | 红色、2 px |
| 数字标记 | 单击添加圆形数字，按创建顺序递增 | 红底白字、24 px |
| 文本 | 单击定位后输入短文本，失焦或确认后落图 | 红色、14 px |

颜色提供红、橙、黄、绿、蓝、黑、白七种固定色，首期不提供任意取色。线宽提供 `2 / 4 / 6 / 8 / 10 / 12 px` 六档；数字标记和文本随线宽按预设比例调整。用户切换工具或颜色会同步影响后续新建标注，选中已有标注时也会立即更新该对象。

### 标注编辑

- 最近一次创建的标注自动选中；选中后可拖动位置，矩形通过四角控制点调整大小，箭头通过两端控制点调整方向。
- 双击文本标注可重新编辑内容；选中任意标注后可通过 `Delete`/`Backspace` 删除，非文本输入状态下生效。
- 撤销、反撤销至少支持本次会话的 50 个操作；包括新建、移动、样式修改、删除和裁剪变更。
- “清空”会移除全部标注、恢复全图裁剪范围并清空历史记录，回到截图刚打开时的初始状态。
- 数字标记删除后不自动重排，避免用户已说明的编号与图片不一致；新标记编号取当前最大值加一。

### 完成、取消与异常

- “完成”按钮在生成 PNG 和写入剪贴板期间展示处理中状态并禁止重复点击。
- 写入成功：关闭编辑器，显示“截图已复制，可直接粘贴”。
- 写入失败：保留编辑器和标注，展示明确错误，提供“重试复制”和“下载 PNG”（P1；P0 至少保留重试）。
- “取消”不写入剪贴板，也不保留截图。

## 页面与文案

- Popup 在录制区附近增加独立的截图操作，不把截图伪装成录屏的附属能力。
- 右键菜单与录制菜单同属 `Quick Copy` 前缀，但使用独立菜单 ID，录制状态变化不得影响截图入口。
- 典型文案：`截图并标注`、`完成并复制`、`取消`、`截图已复制，可直接粘贴`、`复制截图失败，请重试。`
- 不能截图的页面（Chrome 内部页、Chrome Web Store、PDF、非 HTTP(S) 页面等）不显示右键入口；Popup/快捷键触发时给出“当前页面不支持截图”的提示。

## 隐私与数据处理

- 截图只在用户显式触发后获取，采集范围仅为当前活动标签页可视区域。
- 图片与标注只存在于当前编辑会话内存中；完成、取消、失败退出后立即释放。
- 不上传网络、不写入 `storage.sync`/`storage.local`、不自动下载，也不进入录屏历史。
- 剪贴板会被最终 PNG 覆盖，这是“完成并复制”的明确用户动作；扩展不读取现有剪贴板内容。

## 验收标准

- [ ] Popup、右键菜单和快捷键均能在 HTTP(S) 活动标签页打开同一套截图编辑器。
- [ ] 截图源内容不包含编辑器遮罩、工具栏和鼠标操作痕迹。
- [ ] 裁剪后导出的图片尺寸与选区一致，且标注在正确位置、线宽和颜色正确。
- [ ] 矩形框、箭头、画笔、数字标记、文本、颜色和线宽均可使用。
- [ ] 撤销、重做、移动和删除标注不会导致图片或画布错位。
- [ ] 点击完成后，可在至少一个图片型缺陷平台和一个即时通信工具中直接粘贴图片。
- [ ] 剪贴板失败时不丢失编辑结果，可重试；取消时不修改剪贴板。
- [ ] 连续执行两次截图时，仅第二次编辑器保留，第一次会话安全释放。
- [ ] 不支持页面、页面导航和权限异常都有明确提示，且不影响页面原有功能。
