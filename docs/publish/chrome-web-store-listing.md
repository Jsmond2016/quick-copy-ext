### 详细描述（完整版，可直接复制）

```
Quick Copy Ext 是一个面向 Web 开发者和测试人员的浏览器扩展，旨在减少异常反馈时前后端的沟通成本。

主要功能：

• 自动捕获接口请求记录 — 监听当前页面的 XHR 请求，自动收集 URL、方法、状态码、请求/响应头、traceId、耗时等信息。
• 智能过滤与勾选 — 支持按接口前缀地址过滤请求列表，可单选或按住 Shift 连续多选异常接口。
• 一键复制标准化反馈 — 将勾选的接口信息、页面 URL、页面标题等整理为结构化文本，一键复制到剪贴板。
• 响应规则异常检测 — 支持自定义响应体判断规则（如 res.rtn !== 0），自动标记业务逻辑异常。
• Apifox 接口关联 — 支持对接本地 Apifox 导出服务，自动关联接口文档地址和接口名称。
• 自定义字段 — 支持添加自定义字段（如"反馈人-张三"），随反馈内容一并复制。
• 快速填入模板 — 支持预设常见反馈模板，快速选择填入备注。
• 配置导入/导出 — 监听规则、过滤规则等配置支持 JSON 导入导出，方便团队共享。

适用场景：

• 测试人员提交 Bug 时，快速提供完整的接口异常信息。
• 前后端联调时，快速整理接口调用记录供双方确认。
• 日常开发中，需要复制某组接口信息进行讨论和分析。
```

## 2. 隐私与权限

### 2.1 权限声明（Permissions）

> **注意**：以下内容用于填写商店 "Privacy" 或 "Permission Justification" 部分的权限说明。请完整填写，尤其需要逐条解释每个权限的必要性。

| 权限 | 用途说明 |
|------|----------|
| **activeTab** | 获取当前活动标签页的 URL 和页面标题，用于在反馈内容中附带页面信息。仅在用户点击扩展图标时临时生效，不会在后台持续读取所有标签页。 |
| **tabs** | 用于监听标签页 URL 变化（如 SPA 路由切换）以重新判断是否需要捕获请求；在标签页关闭时自动清理该标签页的请求记录缓存。 |
| **webRequest** | 监听页面 XHR 请求的发起、完成和错误事件，用于自动捕获请求 URL、HTTP 方法、状态码、请求头（含 traceId）、响应耗时等调试信息。不会读取或修改请求/响应体内容（响应体通过注入的页面脚本另取途径捕获）。 |
| **storage** | - 使用 `storage.sync` 持久化用户配置（监听域名规则、接口前缀过滤、自定义字段、Apifox 导出地址等）。<br>- 使用 `storage.session` 在浏览器会话期间缓存请求记录和 Apifox 接口数据，在 Service Worker 重启后恢复现场。 |

### 2.2 主机权限（Host Permissions）说明

| 权限 | 用途说明 |
|------|----------|
| **<all_urls>** | 扩展需要在用户配置的任意域名上捕获 XHR 请求记录以辅助调试，因此需要所有 URL 的访问权限。扩展仅在用户配置的监听域名范围内（默认为 localhost 和 127.0.0.1）记录请求数据，不会无差别收集所有站点的信息。 |

### 2.3 Content Script 说明

扩展在所有页面注入 content script，用于注入辅助脚本以捕获接口响应体数据。详见"数据收集说明"。

### 2.4 数据收集说明（Data Usage）

请在商店的 "Privacy" 部分按以下内容填写：

```
数据收集与使用：

1. 扩展不会收集、上传或分享任何用户数据到远程服务器。
2. 所有数据（包括接口请求记录、URL、页面标题、响应体快照）仅在本地浏览器中处理，不会离开用户的设备。
3. 用户配置通过 chrome.storage.sync 保存，仅用于在已登录同一 Google 账号的 Chrome 浏览器之间同步配置。
4. 扩展不会读取或存储用户的浏览历史、书签、密码或其他个人信息。
5. 扩展仅在用户点击扩展图标打开弹出面板时，才会读取当前标签页的信息并展示捕获的请求记录。
6. 请求记录的响应体快照仅用于业务异常规则判断（如 res.rtn !== 0），快照大小经过裁剪（最多 20 个 key、嵌套 3 层、字符串截断至 300 字符），用完即弃。
7. 扩展不会向任何第三方服务发送数据。
```

### 2.5 远程代码说明

本扩展不执行任何远程代码，所有代码均打包在扩展包内。不涉及 Code integrity 或 Remote script 的相关要求。
