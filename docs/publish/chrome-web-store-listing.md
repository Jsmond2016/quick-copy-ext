### 详细描述（完整版，可直接复制）

```
Quick Copy Ext 是一个面向 Web 开发者和测试人员的浏览器扩展，旨在减少异常反馈时前后端的沟通成本。

主要功能：

• 自动捕获接口请求记录 — 监听当前页面的 XHR 请求，自动收集 URL、方法、状态码、请求/响应头、traceId、耗时等信息。
• 智能过滤与勾选 — 支持按接口前缀地址过滤请求列表，可单选或按住 Shift 连续多选异常接口。
• 一键复制标准化反馈 — 将勾选的接口信息、页面 URL、页面标题等整理为结构化文本，一键复制到剪贴板。
• 响应规则异常检测 — 支持自定义响应体判断规则（如 res.rtn !== 0），自动标记业务逻辑异常。
• Apifox 接口关联 — 支持对接本地 Apifox 导出服务，自动关联接口文档地址和接口名称。
• 截图标注并复制 — 支持对当前页面截图、标注，并将标注后的 PNG 图片写入系统剪贴板。
• 当前页面/窗口录制 — 支持用户主动发起当前标签页或当前窗口录制，停止后保存为本地 WebM 文件。
• 自定义字段 — 支持添加自定义字段（如"反馈人-张三"），随反馈内容一并复制。
• 快速填入模板 — 支持预设常见反馈模板，快速选择填入备注。
• 配置导入/导出 — 监听规则、过滤规则等配置支持 JSON 导入导出，方便团队共享。

适用场景：

• 测试人员提交 Bug 时，快速提供完整的接口异常信息。
• 前后端联调时，快速整理接口调用记录供双方确认。
• 日常开发中，需要复制某组接口信息进行讨论和分析。
```

## 2. 隐私与权限

### 2.1 权限声明（Permissions）

> **注意**：以下内容用于填写商店 "Privacy" 或 "Permission Justification" 部分的权限说明。请完整填写，尤其需要逐条解释每个权限的必要性。

| 权限 | 用途说明 |
|------|----------|
| **activeTab** | 获取当前活动标签页的 URL 和页面标题，用于在反馈内容中附带页面信息。仅在用户点击扩展图标时临时生效，不会在后台持续读取所有标签页。 |
| **tabs** | 用于监听标签页 URL 变化（如 SPA 路由切换）以重新判断是否需要捕获请求；在标签页关闭时自动清理该标签页的请求记录缓存。 |
| **webRequest** | 监听页面 XHR 请求的发起、完成和错误事件，用于自动捕获请求 URL、HTTP 方法、状态码、请求头（含 traceId）、响应耗时等调试信息。不会读取或修改请求/响应体内容（响应体通过注入的页面脚本另取途径捕获）。 |
| **storage** | - 使用 `storage.sync` 持久化用户配置（监听域名规则、接口前缀过滤、自定义字段、Apifox 导出地址等）。<br>- 使用 `storage.session` 在浏览器会话期间缓存请求记录和 Apifox 接口数据，在 Service Worker 重启后恢复现场。 |
| **clipboardWrite** | 在用户点击"复制"或完成截图标注时，将标准化反馈文本或标注后的 PNG 图片写入系统剪贴板。扩展不声明 `clipboardRead`，不会读取用户剪贴板内容。 |
| **downloads** | 在用户主动结束录制后，将扩展生成的 WebM 录屏文件保存到浏览器下载目录，并允许用户从扩展中打开最近一次录屏记录。不会读取、扫描或上传用户本地文件。 |
| **contextMenus** | 在网页右键菜单中提供 Quick Copy 的截图、录制、暂停、继续、停止等入口，方便用户在当前页面主动触发相关功能。 |
| **desktopCapture** | 当用户选择"录制窗口"时，调用浏览器的选择器让用户明确选择要录制的窗口或屏幕来源。扩展不会在未获得用户选择的情况下录制桌面内容。 |
| **offscreen** | Manifest V3 的后台 Service Worker 不能稳定持有长时间媒体流，因此录屏期间使用 offscreen document 承载 `MediaRecorder` 和 Blob 处理。录制结束并完成保存后会释放相关资源。 |
| **scripting** | 在受支持页面中按需注入扩展包内置的 content script，用于打开截图标注编辑器、显示录制状态浮层或补充已失效的内容脚本连接。扩展不注入或执行远程代码。 |
| **tabCapture** | 在用户点击"录制当前页面"或右键菜单录制入口后，获取当前标签页的视频流用于本地录屏。默认不采集音频，录制内容仅保存在用户本地。 |
| **unlimitedStorage** | 用于在本地浏览器中保存最近一次高质量录屏预览，避免大文件预览被普通存储配额提前清理。该数据只保留在本机，不会上传远程服务器。 |

#### Chrome Web Store 逐项权限说明（可直接复制）

```text
activeTab:
用于在用户点击扩展图标、快捷键或右键菜单入口后，读取当前活动标签页的 URL、标题，并在截图功能中捕获当前可见区域。该权限只在用户主动触发时临时生效，不会在后台持续访问所有标签页。

tabs:
用于监听标签页 URL 变化和关闭事件，以便在 SPA 路由切换后重新判断监听范围，并在标签页关闭时清理该标签页的请求记录、录屏状态和截图会话。不会读取或保存用户浏览历史。

webRequest:
用于监听页面 XHR 请求的发起、完成和错误事件，捕获请求 URL、HTTP 方法、状态码、请求头中的 traceId、响应头和耗时，帮助开发者和测试人员生成接口异常反馈。不会修改网络请求，也不会通过 webRequest 读取请求体或响应体。

storage:
用于保存用户配置和本地会话数据。storage.sync 保存监听域名、接口前缀过滤、自定义字段、Apifox 导出地址等配置；storage.session 在当前浏览器会话中缓存请求记录、Apifox 匹配结果和录屏状态。数据仅在浏览器本地/账号同步存储中使用，不会上传到扩展服务器。

clipboardWrite:
用于在用户点击复制按钮或完成截图标注时，将生成的反馈文本或标注后的 PNG 图片写入系统剪贴板。扩展不申请 clipboardRead 权限，不会读取用户剪贴板内容。

downloads:
用于在用户主动结束当前页面或当前窗口录制后，把扩展生成的 WebM 文件保存到浏览器下载目录，并支持用户打开最近一次保存的录屏文件。扩展不会读取、扫描或上传用户本地文件。

contextMenus:
用于在网页右键菜单中显示 Quick Copy 的截图和录制控制入口，包括开始录制、暂停、继续、停止并保存、截图并标注。所有操作都需要用户主动点击菜单项触发。

desktopCapture:
用于"录制窗口"功能。只有在用户主动选择录制窗口时，才会打开浏览器提供的窗口/屏幕选择器，并只录制用户明确选择的来源。扩展不会静默录制桌面或其他应用。

offscreen:
用于录屏期间创建 Manifest V3 offscreen document，以承载 MediaRecorder、Blob 生成和本地保存前的临时处理。录制完成并保存后会释放 Blob URL 并关闭 offscreen document。

scripting:
用于在当前受支持页面按需注入扩展包内置脚本，打开截图标注编辑器或恢复录制状态提示。注入的脚本全部随扩展打包发布，不会加载、注入或执行远程代码。

tabCapture:
用于"录制当前页面"功能。只有在用户主动点击录制按钮或右键菜单录制入口后，才会获取当前标签页的视频流并在本地生成 WebM 文件。默认不采集音频，录制文件不上传远程服务器。

unlimitedStorage:
用于在本地浏览器中保存最近一次高质量录屏预览，避免录屏预览因普通存储配额不足而丢失。该数据只保留在用户本机，可由用户清除，不会上传或共享。
```

### 2.2 主机权限（Host Permissions）说明

| 权限 | 用途说明 |
|------|----------|
| **`<all_urls>`** | 扩展需要在用户配置的任意域名上捕获 XHR 请求记录以辅助调试，因此需要所有 URL 的访问权限。扩展仅在用户配置的监听域名范围内（默认为 localhost 和 127.0.0.1）记录请求数据，不会无差别收集所有站点的信息。 |

#### Chrome Web Store 主机权限说明（可直接复制）

```text
<all_urls>:
Quick Copy Ext 面向 Web 开发和测试调试场景，用户可能需要在任意开发、测试、预发或生产域名上临时捕获 XHR 请求记录，因此需要 <all_urls> 主机权限来支持用户自定义监听域名。扩展默认只监听 localhost 和 127.0.0.1；其他域名必须由用户在设置中主动添加。扩展只在配置命中的域名范围内记录请求调试信息，不会无差别收集所有网站数据。
```

### 2.3 Content Script 说明

扩展在所有页面注入 content script，用于注入辅助脚本以捕获接口响应体数据。详见"数据收集说明"。

### 2.4 数据收集说明（Data Usage）

请在商店的 "Privacy" 部分按以下内容填写：

```
数据收集与使用：

1. 扩展不会收集、上传或分享任何用户数据到远程服务器。
2. 所有数据（包括接口请求记录、URL、页面标题、响应体快照）仅在本地浏览器中处理，不会离开用户的设备。
3. 用户配置通过 chrome.storage.sync 保存，仅用于在已登录同一 Google 账号的 Chrome 浏览器之间同步配置。
4. 扩展不会读取或存储用户的浏览历史、书签、密码或其他个人信息。
5. 扩展仅在用户点击扩展图标打开弹出面板时，才会读取当前标签页的信息并展示捕获的请求记录。
6. 请求记录的响应体快照仅用于业务异常规则判断（如 res.rtn !== 0），快照大小经过裁剪（最多 20 个 key、嵌套 3 层、字符串截断至 300 字符），用完即弃。
7. 剪贴板写入仅发生在用户主动点击复制或完成截图标注后，扩展不会读取剪贴板内容。
8. 录屏文件仅在用户主动开始并停止录制后生成，保存到用户浏览器下载目录；最近一次录屏预览仅保存在本地浏览器存储中。
9. 扩展不会向任何第三方服务发送数据。
```

### 2.5 远程代码说明

本扩展不执行任何远程代码，所有代码均打包在扩展包内。不涉及 Code integrity 或 Remote script 的相关要求。
