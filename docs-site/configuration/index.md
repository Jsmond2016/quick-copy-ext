# 配置参考

Quick Copy Ext 提供了丰富的配置项，帮助你根据实际需求定制插件行为。

## 配置方式

所有配置均在 popup 的设置面板中操作：

1. 打开 popup
2. 点击右上角的"设置"按钮 ⚙️
3. 修改配置项
4. 点击"保存"

保存后轻量配置（如自定义字段）立即生效，部分配置（如监听域名、接口前缀过滤）需要刷新页面后完全生效。
