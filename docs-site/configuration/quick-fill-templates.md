# 快速填入模板

## 概述

快速填入模板用于预设一些常见的备注内容，在反馈时可以快速选择填入，减少重复输入。

## 配置方式

在设置面板的"快速填入模板"区域，每行一个模板内容。

### 示例

```text
列表分页加载异常，请排查
新建/编辑功能提交后无响应
搜索条件无结果，预期应展示数据
页面白屏/报错，详见截图
```

## 使用方式

1. 打开 popup
2. 在备注输入框旁，点击模板选择按钮
3. 选择需要的模板内容
4. 模板内容自动填入备注输入框
5. 可按需编辑后再复制

## 适用场景

- 测试人员常用的 Bug 描述模板
- 联调时常见问题描述
- 需要在反馈中附带的标准说明
