# 自定义字段

## 概述

自定义字段用于在每次复制的反馈内容末尾附加固定的信息，例如反馈人、项目名称、环境等。

## 配置方式

在设置面板的"自定义字段"区域，每行一个字段，格式为 `字段名-字段值`。

### 示例

```text
反馈人-张三
项目-管理后台
环境-测试环境
```

## 复制效果

配置后，每次复制反馈内容时，自定义字段会自动附加在内容末尾：

```
---

- 反馈人-张三
- 项目-管理后台
- 环境-测试环境

=== From Quick Copy Ext
```

## 适用场景

- 反馈责任人标识
- 项目或模块归类
- 环境标识
- 其他需要每次附带的固定信息
