# 接口前缀过滤

## 概述

`apiPrefixes` 配置项用于按接口路径前缀过滤展示。在实际使用中，页面可能发起多种类型的请求，但用户通常只关心特定前缀下的接口。

## 默认值

```
["/api/saas/"]
```

## 配置规则

- 每个条目为一个 URL 路径前缀
- 系统会检查请求 URL 的路径部分是否以配置的前缀开头
- 支持配置多个前缀

### 示例

```json
[
  "/api/saas/",
  "/api/user/",
  "/api/order/"
]
```

## 过滤范围

- **展示过滤**：不匹配前缀的请求不在 popup 列表中展示
- **复制过滤**：复制时仅带出符合过滤条件且被勾选的接口
- **监听不过滤**：扩展仍会监听所有请求（在监听域名范围内），只是不在 UI 中展示

## 注意事项

- 修改后需要**刷新页面**才能完全生效
- 前缀匹配是字符串前缀匹配，不是正则表达式
- 如需显示全部接口，保持数组为空或配置更宽泛的前缀
