# 快速上手

本文档演示从发现页面异常到复制反馈内容的完整流程。

## 第一步：复现问题

在浏览器中打开目标页面，进行正常操作以复现问题。扩展会在后台自动监听当前页面的接口请求。

## 第二步：打开扩展面板

点击浏览器工具栏中的扩展图标 ![icon](/icon-32.png)，打开 Quick Copy Ext 弹出面板。

面板打开后，会自动加载当前页面的基本信息（URL、标题）和已捕获的接口请求列表。

## 第三步：查看请求列表

请求列表会展示当前页面捕获到的所有接口请求，默认按请求时间倒序排列。每个请求项包含：

- HTTP 方法（GET / POST / PUT 等）
- 接口路径
- 状态码
- 耗时
- 请求时间
- （如已配置）Apifox 接口名称

如果接口包含异常响应（状态码非 2xx 或命中自定义异常规则），会显示异常标识。

## 第四步：勾选目标接口

选中需要反馈的接口：

- **单选**：点击复选框
- **多选**：按住 `Shift` 键点击，可连续多选
- **全选**：可通过过滤结果全选当前筛选列表

## 第五步：补充备注（可选）

在备注输入框中补充问题描述或说明文字。如有配置快速填入模板，可一键选择模板内容。

## 第六步：复制反馈

点击"复制"按钮，扩展会将以下信息按统一格式写入剪贴板：

- 当前页面 URL 和标题
- 环境信息（如已配置）
- 勾选的接口详情（方法、路径、traceId、状态码、耗时等）
- Apifox 接口链接（如已配置）
- 接口入参（可选）
- 备注内容
- 自定义字段

复制成功后，面板顶部会显示成功提示。

## 第七步：粘贴反馈

在任意编辑器中粘贴（`Ctrl+V` / `Cmd+V`），即可获取格式化的反馈内容，直接发送给前后端协作人员。

---

## 示例：反馈文本格式

```
- 问题：列表分页数据加载异常
- 截图：-

=== 页面接口信息如下

Web 信息：

- 页面 URL：https://example.com/user/list
- 页面标题：用户列表
- 环境测试环境：https://test.example.com

接口信息-1条接口：

- 接口名: 查询用户列表
- POST /api/user/queryList
- traceId: a1b2c3d4e5f6
- 状态码: 200
- 异常原因: 列表为空
- 请求时间: 14:30:25
- 耗时: 248 ms
- apifox: https://app.apifox.com/project/12345/apis/api-67890

---

- 反馈人-张三

=== From Quick Copy Ext
```
