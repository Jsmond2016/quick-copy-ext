# 常见问题

## 安装与加载

### 扩展图标显示为灰色？

扩展默认仅监听 `localhost` 和 `127.0.0.1` 域名的请求。如果你在非本地域名下使用，需要在设置中配置监听域名。图标灰色表示当前页面不在监听范围内。

### 加载构建产物后，插件没有生效？

请确认：

1. 已打开"开发者模式"
2. 加载的目录是 `dist_chrome/`（Chrome）或对应的构建输出目录
3. 构建产物是最新版本（`pnpm build`）

## 功能使用

### popup 中没有看到接口请求记录？

可能的原因：

1. 当前页面不在监听域名内（可在设置中查看和修改 `monitoredOrigins`）
2. 接口请求需要在打开 popup **之前** 就发起，popup 打开后新发起的请求会持续追加
3. 接口路径不符合 `apiPrefixes` 过滤规则（检查设置中的接口前缀过滤）
4. 页面使用的是 WebSocket，扩展不捕获 WebSocket 请求

### 为什么有些接口没有被捕获？

扩展通过 `chrome.webRequest` 监听 `XMLHttpRequest` 和 `fetch` 类型的请求。以下情况不会被捕获：

- 非 `xmlhttprequest` / `fetch` 类型的网络请求（如图片、CSS 等静态资源）
- WebSocket 连接
- 页面自身的导航请求
- 不在监听域名范围内的请求

### 如何清空请求记录？

点击请求列表上方的"清空"按钮，即可清除当前标签页的所有请求记录。

### 复制内容中包含不需要的信息？

你可以在设置中进行以下调整：

- 关闭"包含接口入参"选项，复制结果中将不包含请求参数
- 通过接口前缀过滤，只展示和复制特定前缀的接口
- 通过自定义字段，添加或删除固定的附加信息

### 异常标识(红色气泡)是如何判断的？

扩展通过两种方式判断接口异常：

1. **HTTP 状态码异常**：状态码 >= 400
2. **业务规则异常**：通过自定义的响应规则表达式判断，默认规则为 `res.rtn !== 0`

你可以在设置中自定义业务异常规则。

## Apifox 相关

### 如何配置 Apifox 关联？

在设置的 **Apifox 接口配置** 区域：

**方式一：Apifox Online API（推荐）**
- Apifox 项目 ID：填写 Apifox 项目的唯一标识
- Apifox Auth Token：在 Apifox 中生成 Personal Access Token

**方式二：本地导出服务**
- Apifox 导出 URL：`http://127.0.0.1:4523/export/openapi?projectId={PROJECT_ID}`

保存配置后，扩展会自动在后台刷新 Apifox 数据。

### Apifox 状态灯为灰色？

表示 Apifox 数据未就绪，可能的原因：

1. 未配置 Apifox 导出地址或项目 ID
2. 配置的导出地址不可达（如本地 Apifox 软件未打开）
3. Apifox Auth Token 不正确
4. 数据正在刷新中，可点击刷新按钮重新触发

## 配置相关

### 配置保存在哪里？

配置通过 `chrome.storage.sync` 保存，会同步到登录同一账号的浏览器。

### 如何迁移配置到其他设备？

在设置面板中，使用"导出配置"功能导出为 JSON 文件。在其他设备上通过"导入配置"功能导入。

### 配置保存后需要刷新页面吗？

监听域名、接口前缀过滤等配置修改后，需要刷新页面才会完全生效。
