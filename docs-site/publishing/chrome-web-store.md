## 详细描述

```
Quick Copy Ext 是一个面向 Web 开发者和测试人员的浏览器扩展，旨在减少异常反馈时前后端的沟通成本。

主要功能：

• 自动捕获接口请求记录 — 监听当前页面的 XHR 请求，自动收集 URL、方法、状态码、请求/响应头、traceId、耗时等信息。
• 智能过滤与勾选 — 支持按接口前缀地址过滤请求列表，可单选或按住 Shift 连续多选异常接口。
• 一键复制标准化反馈 — 将勾选的接口信息、页面 URL、页面标题等整理为结构化文本，一键复制到剪贴板。
• 响应规则异常检测 — 支持自定义响应体判断规则（如 res.rtn !== 0），自动标记业务逻辑异常。
• Apifox 接口关联 — 支持对接本地 Apifox 导出服务，自动关联接口文档地址和接口名称。
• 截图标注并复制 — 支持对当前页面截图、标注，并将标注后的 PNG 图片写入系统剪贴板。
• 当前页面/窗口录制 — 支持用户主动发起当前标签页或当前窗口录制，停止后保存为本地 WebM 文件。
• 自定义字段 — 支持添加自定义字段（如"反馈人-张三"），随反馈内容一并复制。
• 快速填入模板 — 支持预设常见反馈模板，快速选择填入备注。
• 配置导入/导出 — 监听规则、过滤规则等配置支持 JSON 导入导出，方便团队共享。

适用场景：

• 测试人员提交 Bug 时，快速提供完整的接口异常信息。
• 前后端联调时，快速整理接口调用记录供双方确认。
• 日常开发中，需要复制某组接口信息进行讨论和分析。
```

## 权限说明

| 权限 | 用途 |
|------|------|
| activeTab | 用户主动触发扩展后，读取当前活动标签页 URL、标题，并用于截图当前可见区域 |
| tabs | 监听标签页 URL 变化和关闭事件，更新监听状态并清理请求、截图、录屏会话缓存 |
| webRequest | 监听页面 XHR 请求的发起、完成和错误事件，捕获 URL、方法、状态码、请求/响应头、traceId、耗时等调试信息 |
| storage | 使用 storage.sync 持久化配置，storage.session 缓存请求记录、Apifox 匹配结果和录屏状态 |
| clipboardWrite | 用户点击复制或完成截图标注后，写入反馈文本或标注后的 PNG 图片；不读取剪贴板内容 |
| downloads | 用户停止录制后，将生成的 WebM 文件保存到浏览器下载目录；不读取或上传本地文件 |
| contextMenus | 在网页右键菜单中提供截图、录制、暂停、继续、停止并保存等用户主动触发入口 |
| desktopCapture | 用户选择"录制窗口"时打开浏览器选择器，只录制用户明确选择的窗口或屏幕来源 |
| offscreen | 录屏期间使用 MV3 offscreen document 承载 MediaRecorder 和 Blob 临时处理，保存完成后释放资源 |
| scripting | 按需注入扩展包内置 content script，用于截图编辑器和录制状态提示；不加载远程代码 |
| tabCapture | 用户选择"录制当前页面"后捕获当前标签页视频流，默认不采集音频，录制文件保存在本地 |
| unlimitedStorage | 在本地浏览器中保存最近一次高质量录屏预览，避免普通存储配额导致预览丢失 |

## 可复制权限说明

```text
clipboardWrite:
用于在用户点击复制按钮或完成截图标注时，将生成的反馈文本或标注后的 PNG 图片写入系统剪贴板。扩展不申请 clipboardRead 权限，不会读取用户剪贴板内容。

downloads:
用于在用户主动结束当前页面或当前窗口录制后，把扩展生成的 WebM 文件保存到浏览器下载目录，并支持用户打开最近一次保存的录屏文件。扩展不会读取、扫描或上传用户本地文件。

scripting:
用于在当前受支持页面按需注入扩展包内置脚本，打开截图标注编辑器或恢复录制状态提示。注入的脚本全部随扩展打包发布，不会加载、注入或执行远程代码。

tabCapture:
用于"录制当前页面"功能。只有在用户点击录制按钮或右键菜单录制入口后，才会获取当前标签页的视频流并在本地生成 WebM 文件。默认不采集音频，录制文件不上传远程服务器。

desktopCapture:
用于"录制窗口"功能。只有在用户主动选择录制窗口时，才会打开浏览器提供的窗口/屏幕选择器，并只录制用户明确选择的来源。扩展不会静默录制桌面或其他应用。

offscreen:
用于录屏期间创建 Manifest V3 offscreen document，以承载 MediaRecorder、Blob 生成和本地保存前的临时处理。录制完成并保存后会释放 Blob URL 并关闭 offscreen document。

unlimitedStorage:
用于在本地浏览器中保存最近一次高质量录屏预览，避免录屏预览因普通存储配额不足而丢失。该数据只保留在用户本机，可由用户清除，不会上传或共享。

contextMenus:
用于在网页右键菜单中显示 Quick Copy 的截图和录制控制入口，包括开始录制、暂停、继续、停止并保存、截图并标注。所有操作都需要用户主动点击菜单项触发。
```

## 主机权限说明

```text
<all_urls>:
Quick Copy Ext 面向 Web 开发和测试调试场景，用户可能需要在任意开发、测试、预发或生产域名上临时捕获 XHR 请求记录，因此需要 <all_urls> 主机权限来支持用户自定义监听域名。扩展默认只监听 localhost 和 127.0.0.1；其他域名必须由用户在设置中主动添加。扩展只在配置命中的域名范围内记录请求调试信息，不会无差别收集所有网站数据。
```

## 数据收集说明

扩展不会收集、上传或分享任何用户数据到远程服务器。所有数据仅在本地浏览器中处理。

```text
数据收集与使用：

1. 扩展不会收集、上传或分享任何用户数据到远程服务器。
2. 所有数据（包括接口请求记录、URL、页面标题、响应体快照、截图标注结果和录屏预览）仅在本地浏览器中处理，不会离开用户的设备。
3. 用户配置通过 chrome.storage.sync 保存，仅用于在已登录同一 Google 账号的 Chrome 浏览器之间同步配置。
4. 扩展不会读取或存储用户的浏览历史、书签、密码或其他个人信息。
5. 扩展仅在用户主动打开弹出面板、点击复制、启动截图或启动录屏时访问当前页面所需信息。
6. 剪贴板写入仅发生在用户主动点击复制或完成截图标注后，扩展不会读取剪贴板内容。
7. 录屏文件仅在用户主动开始并停止录制后生成，保存到用户浏览器下载目录；最近一次录屏预览仅保存在本地浏览器存储中。
8. 扩展不会向任何第三方服务发送数据。
```
