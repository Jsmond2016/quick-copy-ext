# Chrome Web Store 发布

## 基础信息

| 字段 | 内容 |
|------|------|
| **扩展名称** | Quick Copy Ext |
| **摘要** | 快速整理当前页面接口信息，并一键复制反馈内容。 |
| **类别** | Developer Tools |
| **界面语言** | 简体中文 |

## 详细描述

```
Quick Copy Ext 是一个面向 Web 开发者和测试人员的浏览器扩展，旨在减少异常反馈时前后端的沟通成本。

主要功能：

• 自动捕获接口请求记录 — 监听当前页面的 XHR 请求，自动收集 URL、方法、状态码、请求/响应头、traceId、耗时等信息。
• 智能过滤与勾选 — 支持按接口前缀地址过滤请求列表，可单选或按住 Shift 连续多选异常接口。
• 一键复制标准化反馈 — 将勾选的接口信息、页面 URL、页面标题等整理为结构化文本，一键复制到剪贴板。
• 响应规则异常检测 — 支持自定义响应体判断规则（如 res.rtn !== 0），自动标记业务逻辑异常。
• Apifox 接口关联 — 支持对接本地 Apifox 导出服务，自动关联接口文档地址和接口名称。
• 自定义字段 — 支持添加自定义字段（如"反馈人-张三"），随反馈内容一并复制。
• 快速填入模板 — 支持预设常见反馈模板，快速选择填入备注。
• 配置导入/导出 — 监听规则、过滤规则等配置支持 JSON 导入导出，方便团队共享。

适用场景：

• 测试人员提交 Bug 时，快速提供完整的接口异常信息。
• 前后端联调时，快速整理接口调用记录供双方确认。
• 日常开发中，需要复制某组接口信息进行讨论和分析。
```

## 权限说明

| 权限 | 用途 |
|------|------|
| activeTab | 获取当前活动标签页的 URL 和页面标题 |
| tabs | 监听标签页 URL 变化，清理关闭标签页的缓存 |
| webRequest | 监听页面 XHR 请求的发起、完成和错误事件 |
| storage | 使用 storage.sync 持久化配置，storage.session 缓存请求记录 |

## 数据收集说明

扩展不会收集、上传或分享任何用户数据到远程服务器。所有数据仅在本地浏览器中处理。
