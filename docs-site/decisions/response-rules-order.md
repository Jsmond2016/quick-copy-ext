# 异常响应规则顺序控制

> **编写时间**：2026-06-01；**使用模型**：GPT-5 Codex

## 背景

当前插件设置中的"异常响应规则"字段用于配置接口返回异常的判定逻辑。业务目标明确为：

- 一个接口只命中一条异常规则
- 规则判断顺序完全由用户配置顺序决定

## 方案

规则统一使用 JSON 数组格式，按数组顺序依次判断，首条命中即停。

### 配置格式

```json
[
  {
    "label": "无权限",
    "expression": "res.rtn === 403"
  },
  {
    "label": "接口异常",
    "expression": "res.rtn !== 0"
  }
]
```

### 行为语义

1. 从第一条规则开始计算表达式
2. 若未命中则继续下一条
3. 若命中则立即返回该规则
4. 后续规则不再继续判断

## 涉及文件

- `src/lib/quick-copy/response-rules.ts` — 类型、解析、命中逻辑改造
- `src/lib/quick-copy/constants.ts` — 默认配置更新
- `src/pages/popup/components/SettingsPanel.tsx` — 面板文案更新

## 验证场景

1. 403 场景优先命中"无权限"，不继续命中"异常"
2. "下拉为空"与"列表为空"按顺序互斥判断
3. 非数组格式被拒绝保存
4. 保存、导入、重置后规则均正常显示和校验
