# 反馈文本格式

## 概述

复制后的反馈内容按照统一的结构化格式组织，包含页面信息、接口详情、备注和自定义字段。

## 标准格式

```text
- 问题：[用户备注]
- 截图：[截图标签 / -]

=== [反馈标题]

Web 信息：

- 页面 URL：[当前页面 URL]
- 页面标题：[当前页面标题]
- 环境[环境名称]：[环境 URL]  （可选）

接口信息-[N]条接口：

- 接口名: [接口名称]  （来自 Apifox，可选）
- [请求方法] [请求路径]
- traceId: [traceId / -]
- 状态码: [状态码 / -]
- 异常原因: [异常原因]  （仅异常时显示）
- 请求时间: [HH:MM:SS]
- 耗时: [N ms]
- 接口大小: [N B / KB]
- apifox: [Apifox 链接]  （可选）
- 接口入参: [格式化 JSON]  （可选）

---
- [自定义字段]

=== From Quick Copy Ext
```

## 字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| 问题 | 否 | 用户在备注中输入的问题描述 |
| 截图 | 否 | 截图标识，当前版本固定为 `-` |
| 反馈标题 | 是 | 默认为"页面接口信息如下"，可在设置中修改 |
| 页面 URL | 是 | 当前标签页的完整 URL |
| 页面标题 | 是 | 当前标签页的页面标题 |
| 环境 | 否 | 已选择的环境信息 |
| 接口名 | 否 | Apifox 匹配到的接口中文名称 |
| 请求方法 | 是 | HTTP 请求方法 |
| 请求路径 | 是 | 接口 URL 路径 |
| traceId | 是 | 请求链路追踪标识，不存在时显示 `-` |
| 状态码 | 是 | HTTP 响应状态码 |
| 异常原因 | 否 | 仅请求异常时显示（状态码 >= 400 或命中异常规则） |
| 请求时间 | 是 | 接口请求发起时间 |
| 耗时 | 是 | 请求完成耗时 |
| 接口大小 | 否 | 响应体大小 |
| apifox 链接 | 否 | Apifox 接口文档链接 |
| 接口入参 | 否 | 请求参数（需在复制选项中开启） |
| 自定义字段 | 否 | 用户在设置中配置的固定附加字段 |

## 复制选项

在复制前，可通过面板上的选项控制复制内容：

- **包含接口入参**：复制结果中是否包含请求参数
- **包含环境信息**：复制结果中是否包含环境标识

## 示例

```text
- 问题：列表分页加载异常，点击第2页后数据未更新
- 截图：-

=== 页面接口信息如下

Web 信息：

- 页面 URL：https://example.com/user/list?page=1
- 页面标题：用户管理

接口信息-2条接口：

- 接口名: 查询用户列表
- GET /api/saas/user/list?page=1&size=20
- traceId: abc123def456
- 状态码: 200
- 请求时间: 14:30:25
- 耗时: 248 ms
- apifox: https://app.apifox.com/project/12345/apis/api-67890

- POST /api/saas/user/queryList
- traceId: abc123def457
- 状态码: 500
- 异常原因: 服务器内部错误
- 请求时间: 14:30:26
- 耗时: 1024 ms

---

- 反馈人-张三
- 项目-管理后台

=== From Quick Copy Ext
```
