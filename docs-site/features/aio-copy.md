# AIO 一键复制（测试者模式）

## 概述

AIO（All-In-One）是测试者模式下的专属功能，支持将反馈内容复制到剪贴板的同时，在新标签页中打开指定的 Bug 提交页面，帮助测试人员快速提交缺陷。

## 前置条件

1. 在设置中将模式切换为 **测试者模式**（`tester`）
2. 配置测试者 AIO 配置，包含：
   - **迭代名称**：测试迭代的标识
   - **Bug 提交 URL**：提交 Bug 时的目标页面地址

## 使用方式

1. 选择迭代（如存在多个 AIO 配置）
2. 勾选需要反馈的接口
3. 补充备注信息
4. 点击"复制到 AIO"
5. 扩展自动执行：
   - 复制格式化反馈内容到剪贴板
   - 在新标签页中打开 Bug 提交页面

## 适用场景

- 测试人员提交 Bug 时，快速提供完整的异常反馈信息
- 批量处理多个问题的提交流程
- 减少在 Bug 系统和页面之间切换的步骤
