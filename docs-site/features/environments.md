# 多环境切换

## 概述

扩展支持配置多套环境（如开发环境、测试环境、预发布环境），在 popup 中可一键切换和跳转，同时保留当前页面的路径。

## 配置方式

在设置面板中，可以添加多个环境配置：

| 字段 | 说明 | 示例 |
|------|------|------|
| 环境名称 | 环境的显示名称 | 开发环境、测试环境 |
| 环境 URL | 环境的基础 URL | `https://dev.example.com` |

## 使用方式

### 环境标签

配置环境后，popup 顶部会显示环境标签，如：

- `dev` 🟢（开发环境）
- `test` 🟡（测试环境）

### 环境跳转

点击环境标签，扩展会在新标签页中打开对应环境的基础 URL。

### 复制环境信息

在复制选项中勾选"包含环境信息"后，复制结果中会附带当前选择的环境名称和 URL。

## 适用场景

- 在不同环境间快速切换，测试同一功能
- 反馈内容中附带环境信息，帮助协作方快速定位问题环境
- 多环境部署的项目，快速访问不同版本的页面
