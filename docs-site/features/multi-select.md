# 请求多选与复制

> **更新时间**：2026-07-14；**使用模型**：Codex（GPT-5）；**用户**：Jsmond2016

---

## 选择方式

扩展支持灵活的选择操作：

**单选**：直接点击接口项的复选框。

**连续多选**：按住 `Shift` 键，点击另一个接口项的复选框，即可选中从当前选中项到目标项之间的所有接口。

**全部选中**：当启用了接口前缀过滤后，可通过"全选当前筛选结果"快速选中所有显示的接口。

## 选择状态

- 选中的接口会高亮显示
- 面板顶部会显示已选数量
- 复制时仅复制选中的接口信息

## 复制操作

点击"复制"按钮，将所有选中的接口信息连同页面信息、备注等按标准化格式写入剪贴板。

复制成功后，面板顶部会显示成功提示，包含已写入的接口数量。

### 单接口快捷复制

每条请求右侧提供独立复制按钮。点击后不会勾选或取消勾选请求，只复制当前接口的简要信息：

```text
GET /api/user/list [查询用户列表]
```

方括号中的接口名来自 Apifox 匹配结果；未匹配到接口名时，复制内容仅包含请求方法和完整路径（含查询参数与 hash）。
