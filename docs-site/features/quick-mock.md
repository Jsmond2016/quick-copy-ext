# Quick Mock（开发者模式）

## 概述

Quick Mock 是开发者模式下的专属功能，支持将选中的接口请求批量发送到指定的 Mock 扩展，帮助前端开发者在后端接口尚未就绪时快速调试。

## 前置条件

1. 在设置中将模式切换为 **开发者模式**（`developer`）
2. 安装并配置 Quick Mock 扩展
3. 在设置中填写 Quick Mock 目标扩展 ID

## 使用方式

1. 勾选需要 Mock 的接口
2. 点击"快速 Mock"按钮
3. 扩展会将选中的接口信息发送到 Quick Mock 扩展
4. Quick Mock 扩展自动创建对应的 Mock 规则

## 适用场景

- 后端接口尚未开发完成，前端需要先行调试
- 需要批量创建多个接口的 Mock 数据
- 联调过程中需要快速模拟特定接口的异常返回
